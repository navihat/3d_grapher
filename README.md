# 3D Function Grapher on Paper — Đề tài 2615

App AR vẽ đồ thị hàm số 2D/3D nổi trên phiếu bài tập in, kèm bài tập có hướng dẫn. Unity + Vuforia, chạy trên Android.

## Cài đặt

1. Cài **Unity 6000.6.4f1** qua Unity Hub, kèm module Android Build Support.
2. Cài **Git LFS** (`sudo apt install git-lfs` hoặc tải từ git-lfs.com), rồi chạy `git lfs install` một lần.
3. Clone repo, mở thư mục gốc bằng Unity Hub (Add project from disk).
4. VS Code: cài extension **Unity** (kèm C# Dev Kit); trong Unity chọn *Edit → Preferences → External Tools → Visual Studio Code*.
